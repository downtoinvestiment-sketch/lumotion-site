# Lumotion Studio — sito web

Sito di [Lumotion Studio](https://lumotionstudioia.com), studio di video AI, social e siti web.

Sito statico (un solo `index.html`, media in `media/`), pubblicato con GitHub Pages dal ramo `gh-pages`.
Non serve toccare `gh-pages` a mano: a ogni push su `main` il workflow «Pubblica il sito» lo allinea a `main` e avvia la pubblicazione.
